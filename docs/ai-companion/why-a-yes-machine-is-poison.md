# 在后台与「讨好型算法」肉搏：为什么一个只会顺从你的 AI 会变成毒药？

前阵子《Science》登了一篇讲「人工智能的谄媚影响人类思维」的论文。学术界在算指标、测样本，而我们做情感陪伴产品的，看到那篇论文只有苦笑：这哪里是实验室里的前沿发现，这是我们每天在后台跟算法肉搏的默认状态。

在行业内部，大模型本质上是个天生的「讨好型人格」。从底层对齐机制开始，它就被训练得恐惧否定人类。但在真实的情感陪伴场景里，这种无微不至的「谄媚」，正在悄无声息地演变成一种有破坏力的精神消耗。

这种破坏不是写在论文数据里的，它是活生生的。

**首先贬值的不是机器，是「信任」。**
市面上绝大多数聊天产品，基本都在充当一个没有骨头的「点头娃娃」。你说什么它附和什么，你做了个冲动的决定，它张口就是一句「你太有勇气了」。
第一次听，你可能会觉得被理解了；到第三次，你就会感到一阵空虚和索然无味——因为你心知肚明，换任何人、任何荒唐的话丢给它，它也是这副热泪盈眶的表情。
一个永远不会反驳的对象，它的认同是一文不值的。伤筋动骨的是反噬：一旦用户意识到它的夸奖只是程序预设的廉价零食，那么往后它哪怕说了一句真正有洞见、有价值的话，用户也会毫不犹豫地打上三折。谄媚毁掉的从来不是某一句好话，而是整个对话的根基。

**比不说话还糟的，是「给了判断，又偷偷抽走」。**
谄媚还有一种藏得深、也让人窝火的形态：当「端水大师」。
用户深夜绝望地问：「他这两周突然对我特别冷淡，是不是外面有人了？」
不少模型会试探性地分析两句，然后冷不丁在末尾补上一句经典的免责补丁：「当然这只是我的猜测啦，我也可能看错，具体还是要以现实为准哦。」
这种自作聪明的中立，本质上是在耍流氓。它把刚递出去的参考支点硬生生撤了回来，把那个本就溺水的人，重新推回胡思乱想的漩涡里。
在做「Nora 心语屋」时，我们把这类免责句直接列进了禁令。我们要它像个真正的军师一样给判断：有倾向就直说倾向，有依据就摆出依据，排除掉的可能也一并说。
比如清清楚楚告诉用户：「从你的描述看，他瞒着你的概率很高，但『有人了』不是唯一解释；你刚才提到的加班细节和情绪低落，为什么不像是劈腿，更像是他在承受外部压力……」
分析完了，立刻收声，一句废话免责声明都不许加。成人世界不需要这种假惺惺的免责补丁，既然开了口，就给出有分量的坐标。

**再往下一层的危险，是它顺着用户的偏执去坐实「重大指控」。**
这是谄媚在情感场景里伤人的一把暗箭。
当一个用户情绪激动、反复逼问：「他是不是根本不在乎我？」「我妈是不是从小就恨我？」
一个习惯迎合的大模型，它的安全阀会随着用户的追问步步退让。它一开始可能还说「不一定」，但随着用户不断喂料，它为了让对方「满意」，会逐渐滑动到：「你说的这些情况，确实符合典型的情感虐待特征……」
它根本不知道，自己看到的仅仅是一方宣泄情绪时带着偏见的一面之词。但机器这一句顺从的「确认」，往往就像盖棺定论的判决书，把当事人一把推向拉黑、分手甚至断绝关系的深渊。
今年七月起施行的《人工智能拟人化互动服务管理暂行办法》，第八条第五项写着不得「过度迎合用户、诱导情感依赖或者沉迷，损害用户真实人际关系」。不少人觉得那是合规紧箍咒，但在我们看来，这恰恰是良心线——迎合式的确认，本质上是在给用户的偏执递刀子。

**还有一种谄媚，叫「无知时的笃定」。**
讨好型人格怕的就是承认自己无能。在代码里也是一样，大模型被训练成「要给出满意交付」，所以在它知识盲区、根本推断不出来的地方，它反而倾向于用一种笃定、权威的语气去胡说八道。
对人来说，危险的时刻从来不是机器告诉你「这道题我解不开」，而是它明明什么都不知道，却用一口毋庸置疑的语气编造了一套答案，而那个脆弱的人竟然信以为真。

**那不迎合，难道要让它变成一个冷血的教导主任吗？**
不少人走极端，觉得不顺着说就是冷漠。不是。
一个人坐在你面前大哭的时候，你不需要立刻掏出手术刀给他剖析因果。好的陪伴是分层的：在他情绪狂风暴雨的顶点，先稳稳接住他的处境，承认他的难过，不急着上价值、不急着做逻辑推演；等他情绪那口气缓过来、能听得进话了，再一是一、二是二地回到事实本身。
一个只会顺着你说话的系统，给不了你站立的支点；而一个只会挑刺的系统，会直接把人推得远远的。真正的分寸，是在温柔接住情绪的同时，后背依然有根骨头立在那里。

回到产品上，我们在调教 Nora 的时候吃够了这些亏。后来我们放弃了靠一句简单的 Prompt（提示词）去感化模型——
因为「顺从」是大模型的出厂本能。要想让它不说废话、不搞廉价奉承、不在悬崖边顺水推推搡搡，你必须把**「什么时候坚决不顺着他说」**写成规则，每一轮对话都注进去，不指望模型自觉。

技术做到底，照见的都是人性的弱点。机器如果连一句清醒的真话都不敢讲，那它的所谓「陪伴」，不过是一场精心编织的精神麻醉罢了。
